# Contributing to VEIL

Fork, branch, open a pull request. **Do not push to `main`.**

`main` is protected:

- Direct pushes from anyone except the maintainer are blocked
- A pull request is required
- It cannot be merged until **@ginxx009** approves
- Pushing more commits after an approval resets the review

## Flow

1. Fork [ginxx009/VEIL](https://github.com/ginxx009/VEIL)
2. Branch from `main`
3. Open a PR against `main`
4. Wait for review. Maintainers merge.

Do not include API keys, resumes, or anything from `~/Library/Application Support/VEIL/` or `%APPDATA%\VEIL`.
